# Reservation System

A trailer rental reservation application developed as a student project at LAB University of Applied Sciences.

## Overview

This Windows application provides functionality for rental companies to manage trailer rentals, customer information, and reservation scheduling. The system allows staff to:

- Manage customer information
- View and create reservations
- Book different types of trailers (Large, Small, Boat)
- Add extra services and accessories to rentals
- Check trailer availability by date

## Features

- Customer database management
- Reservation calendar and scheduling
- Trailer inventory tracking
- Extra services and add-ons
- Simple dashboard interface

## Technology

- C# WinForms
- .NET Framework 4.7.2
- MySQL database (using MySqlConnector)

## Development Team

This project was developed as part of coursework at LAB University of Applied Sciences in Lahti.
